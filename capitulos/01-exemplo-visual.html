Modelos preditivos estimam uma função f(x) a partir de dados ruidosos y = f(x) + \epsilon.

\hat{y} = \mathbb{E}[Y \mid X = x]

Code 
import numpy as np
import plotly.graph_objects as go

np.random.seed(42)
x = np.linspace(0, 10, 120)
y_true = np.sin(x) * np.exp(-0.1 * x)
y_obs = y_true + np.random.normal(0, 0.08, size=len(x))

fig = go.Figure()
fig.add_trace(go.Scatter(x=x, y=y_obs, mode='markers', name='Observações', marker=dict(opacity=0.6)))
fig.add_trace(go.Scatter(x=x, y=y_true, mode='lines', name='Função Real f(x)', line=dict(width=3)))
fig.update_layout(
    title="Sinal Subjacente vs. Dados Ruidosos",
    xaxis_title="Tempo (t)",
    yaxis_title="Valor",
    template="plotly_white"
)
fig.show()

# Exemplo: Regressão e Incerteza

Modelos preditivos estimam uma função $f(x)$ a partir de dados ruidosos $y = f(x) + \epsilon$.

$$
\hat{y} = \mathbb{E}[Y \mid X = x]
$$

::: {.callout-note}
## Como usar este capítulo
Clique em **Code** acima do gráfico se quiser inspecionar ou copiar o script Python que gerou a visualização.
:::

```{python}
import numpy as np
import plotly.graph_objects as go

np.random.seed(42)
x = np.linspace(0, 10, 120)
y_true = np.sin(x) * np.exp(-0.1 * x)
y_obs = y_true + np.random.normal(0, 0.08, size=len(x))

fig = go.Figure()
fig.add_trace(go.Scatter(x=x, y=y_obs, mode='markers', name='Observações', marker=dict(opacity=0.6)))
fig.add_trace(go.Scatter(x=x, y=y_true, mode='lines', name='Função Real f(x)', line=dict(width=3)))
fig.update_layout(
    title="Sinal Subjacente vs. Dados Ruidosos",
    xaxis_title="Tempo (t)",
    yaxis_title="Valor",
    template="plotly_white"
)
fig.show()

```
